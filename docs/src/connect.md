# Як підключитися

Кожен сервіс із цього довідника вимагає, щоб твій пристрій був у
tailnet-мережі. Tailscale - це mesh-VPN: після підключення твій пристрій
говорить із daorus напряму через шифрований WireGuard-тунель, звідки
завгодно - з домашньої мережі чи з мобільного інтернету, різниці немає.

## 1. Отримай запрошення

Попроси в адміністратора інвайт у мережу. Прийде посилання - заходиш під
власним акаунтом (Google/GitHub/тощо), жодних спільних паролів немає.

## 2. Встанови Tailscale

Клієнт для своєї платформи бери на
[tailscale.com/download](https://tailscale.com/download):

| Платформа | Клієнт |
|---|---|
| Android | [Tailscale у Play Store](https://play.google.com/store/apps/details?id=com.tailscale.ipn) |
| iOS | [Tailscale в App Store](https://apps.apple.com/us/app/tailscale/id1470499037) |
| Windows / macOS | Інсталятор зі сторінки завантажень |
| Linux | Пакетний менеджер, потім `sudo tailscale up` |

Заходиш під запрошеним акаунтом - і пристрій у мережі.

## 3. Перевір, що працює

Відкрий <https://docs.faun-castor.ts.net> - якщо ця сторінка відкрилась за
цією адресою, ти підключений.

Кілька речей, які працюють автоматично:

- **MagicDNS** - машини резолвляться за іменем: `daorus`, `dloq`, або
  повністю - `daorus.faun-castor.ts.net`.
- **Імена сервісів** - кожен сервіс має власне ім'я на кшталт
  `jellyfin.faun-castor.ts.net` з публічно довіреним сертифікатом: HTTPS
  просто працює, без портів і попереджень.
- **Блокування реклами** - DNS мережі проходить через
  [Pi-hole](services/pihole.md), тож реклама й трекери фільтруються на
  кожному пристрої без додаткових налаштувань.

## Поради

- Залишай Tailscale увімкненим у фоні: без трафіку він простоює, батарею
  майже не їсть.
- Якщо на телефоні сервіс не відкривається - перевір, що застосунок
  Tailscale підключений: деякі телефони вбивають VPN для економії заряду.
- Стрімінг з-за меж дому працює нормально, але стеля швидкості - це
  upload домашнього інтернету.
