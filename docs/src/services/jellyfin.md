# Jellyfin - фільми, серіали, книги

**Адреса:** <https://jellyfin.faun-castor.ts.net>

Jellyfin - це домашній "Netflix": стрімить медіатеку daorus на будь-який
пристрій. Бібліотеки: фільми, серіали, музика та книги.

## Вхід

Акаунт створює адміністратор - попроси в нього логін і пароль.
Перший вхід: відкрий адресу вище, введи ім'я користувача й пароль. У
застосунках спершу вказується адреса сервера
(`https://jellyfin.faun-castor.ts.net`), потім ті самі логін/пароль.

## Чим дивитися

| Платформа | Рекомендовано | Примітки |
|---|---|---|
| Браузер | вбудований веб-плеєр | найпростіший варіант, нічого ставити не треба |
| Android | [офіційний Jellyfin](https://play.google.com/store/apps/details?id=org.jellyfin.mobile) або [Findroid](https://play.google.com/store/apps/details?id=dev.jdtech.jellyfin) | Findroid - приємніший інтерфейс |
| iOS | [Swiftfin](https://apps.apple.com/us/app/swiftfin/id1604098728) | нативний плеєр, вміє більше форматів |
| Windows / macOS / Linux | [Jellyfin Media Player](https://github.com/jellyfin/jellyfin-media-player/releases) | десктопний клієнт з нормальним відтворенням |
| Android TV | Jellyfin для Android TV з Play Store | |

## Поради

- Якщо відео "крутиться" - сервер транскодує його під твій пристрій; це
  нормально, просто зачекай кілька секунд.
- У мобільних застосунках можна завантажити серії офлайн перед дорогою.
- Книги зручніше читати через веб-інтерфейс або забирати файлом.
