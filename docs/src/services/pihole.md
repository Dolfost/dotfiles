# Pi-hole - DNS

**Адмінка:** <http://daorus.faun-castor.ts.net:8080/admin>

Pi-hole - DNS-сервер, який ріже рекламу й трекери на рівні DNS-запитів:
пристрій питає "де ads.example.com", а у відповідь отримує пустишку.
Працює і для tailnet-мережі, і для домашньої локалки.

## Кому що робити

Звичайним користувачам - нічого. DNS налаштовується автоматично:

- **У tailnet:** глобальний DNS мережі вказує на Pi-hole
  (`100.91.220.75`), тому будь-який пристрій з Tailscale фільтрується
  автоматично, де б він не був.
- **Вдома по WiFi:** роутер роздає Pi-hole (`192.168.0.70`) як DNS через
  DHCP - фільтруються навіть пристрої без Tailscale (телевізор тощо).

## Адмінка

Вхід - пароль адміністратора (задається на daorus командою
`podman exec -it pihole pihole setpassword`, в конфігах його немає).

Що там корисного:

- Query Log - подивитися, чому якийсь сайт не відкривається (може, його
  порізав фільтр).
- Whitelist - розблокувати домен, якщо фільтр зачепив щось потрібне.

## Поради

- Якщо сайт "не працює" на всіх пристроях одразу - перше, що варто
  перевірити, це Query Log: можливо, домен у блоклісті.
- Тимчасово вимкнути фільтрацію можна в адмінці (Disable Blocking) - на
  5 хвилин, потім увімкнеться сама.
