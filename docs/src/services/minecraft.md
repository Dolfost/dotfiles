# Minecraft

**Адреса сервера:** `mc.faun-castor.ts.net`

Сервер Minecraft (Java Edition) на daorus. Порт стандартний (25565), тому
в клієнті достатньо самого імені хоста.

## Як зайти

1. Пристрій має бути в tailnet-мережі (див. [Як підключитися](../connect.md)).
2. Multiplayer -> Add Server.
3. Server Address: `mc.faun-castor.ts.net`
4. Грати.

Логін - твій звичайний акаунт Minecraft, вайтліст і права видає
адміністратор.

## Панель керування (для адмінів)

**Crafty Controller:** <https://crafty.faun-castor.ts.net>

Crafty керує світами, бекапами, версіями та консоллю сервера. Вхід - за
акаунтом Crafty, який створює адміністратор.

## Поради

- Сервер може бути зупинений, коли ніхто не грає - якщо не коннектиться,
  спитай, чи він запущений.
- Пінг залежить від того, наскільки далеко ти від дому: через tailnet
  трафік іде напряму, тож з домашньої мережі це локалка.
